# ADR 0006：签名临时密钥的节点加密会话

- 状态：本机双 App 集成测试通过，仅开放加密 ping；Windows 双机和外部安全审计待完成
- 日期：2026-09-21

在本机登记的双向可信公钥之上，发起方生成临时 X25519 密钥，连同目标 Node ID、时间戳和随机 nonce 由 Ed25519 身份密钥签名。接收方验证公钥、签名、目标、30 秒时间窗和 nonce 防重放后，生成自己的临时 X25519 密钥并签名应答。双方从 X25519 共享秘密与已签名的双方握手 transcript 经 HKDF-SHA256 派生两个独立的 AES-256-GCM 方向密钥。

每个消息的 AAD 包括协议版本、会话 ID、单调计数器和收发节点 ID。12 字节 IV 从方向密钥下的单调计数器确定性构造；会话最多 5 分钟，重放/篡改/过期或撤销信任均被拒绝。关闭 LAN 会清除会话密钥。消息体上限 256 KB；当前服务器只接受加密 `ping` 并回传加密 `pong`，其余操作一律拒绝。

此协议是独立于浏览器 HTTP 的应用层加密边界，不替代 TLS，也不让内网 Web 自动变成 HTTPS。身份签名认证的是节点密钥，不是用户权限；未经外部密码协议安全审计及任务级授权，不传工程、Artifact、Lease 或求解结果，也不允许自动派单。下一阶段要把租约身份、Artifact SHA、传输额度和可恢复分块协议绑定到此加密会话，并做 Windows 双机断网/重连验收。
