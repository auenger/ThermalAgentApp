# ADR 0016：桌面窗口与后台 Core 的生命周期分离

## 状态

代码与非 GUI 测试已实现；真实 Windows 托盘、锁屏、RDP 断开及 Icepak 长任务仍待验收。

## 背景

应用既是工作台，也是本机任务和局域网节点服务。之前 Electron 在最后一个窗口关闭时退出，并终止 Core，这会中断任务、DSH Host 和 LAN 服务，违背桌面优先的交付形态。

## 决策

- Electron 主进程持有单实例锁。重复启动只唤起已有工作台，不创建第二个 SQLite/Core 实例。
- 托盘图标在主进程启动时创建并保留引用。关闭最后一个工作台窗口只销毁窗口，不退出应用；Core 继续运行。
- 托盘提供“打开工作台”和“退出应用”。重新打开窗口复用原 Core 地址，不重复启动 Core。
- 仅显式退出应用时停止 Core 进程。当前退出路径会终止受管进程树；真实 AEDT 长任务的安全取消和许可证释放仍需 Windows 验收，不据此宣称已实现 Windows Service。

## 验证

构建与单元测试覆盖托盘图标 PNG 数据及桌面运行时路径。窗口关闭后的托盘可见性、Core 持续运行、任务不中断和重新打开行为，必须在有桌面会话的 Windows 机器上做 GUI 验收。
