日期：2026-10-12。分支：`experiment/cad-object-context`；基于主线提交 `579445d`。

## 决策与范围

使用独立分支开展 P1 实验。主线已有 CAD 到 Baseline 的实现和试包，正在等待 Windows 工程验收；查看器、几何运行时和对象交互可以在实验分支逐步验证，通过后再按阶段合并。

第一阶段建立对象选择与版本上下文；第二阶段接入真实 STEP 的本地显示网格。复用当前导入目录和配置表，没有新增数据库迁移或 Agent 执行入口。操作说明 HTML 保持当前主线快照。

## 第一阶段原型（已有）

- 在任务详情完成导入并配置一个版本后，点击实体名称选择部件；表格高亮该行。
- 对象面板展示当前角色、材料、功率、监测以及导入版本和对象键。
- “定位配置行”清空筛选并滚动到选中实体；“清除选择”取消当前选择。
- “导出选中对象上下文”输出 JSON，包含 Task、源 SHA、导入 ID、目录 SHA、对象键、几何目录数据与当前配置草稿。导出保留替身证据标识。
- 切换导入或目录身份后丢弃旧选择；重新打开页面也不会自动恢复选择。导出的旧文件使用前仍需重新核对身份。

配置内容来自当前可编辑草稿，可能尚未保存或验证；记录的持久化草稿版本不表示导出内容已冻结。选择和导出不会改变材料、功率，也不会触发建模或求解。第一阶段只提供实体表和静态预览；新增 3D 能力见下一节。当前仍不提供面选择或直接把上下文发送给 Agent。

## 第二阶段：真实 STEP 三维预览

已接入按需加载的 Three.js 视图与 Open CASCADE WASM Worker，读取 App 归档的原始 STEP/STP。无需先导入 Icepak 即可旋转、缩放和点击选择显示部件；支持显示部件清单、隐藏、隔离及显示全部。

- 源文件通过任务限定的只读 API 读取，Worker 在解析前重新计算 SHA。激活生成工程后仍读取原 CAD，不把 AEDT 当作 STEP。
- 源 SHA、导入版本、目录 SHA、显示运行时版本和网格内容 ID 共同限定显示引用。每个网格 ID 包含索引及其顶点/三角形内容 SHA；不能跨源文件或运行时版本沿用。
- 显示部件初始未绑定。用户选择实际目录实体并核对形状、位置和原工程后确认对应关系；mm 单位、Solid 类型和包围盒各坐标 0.05 mm 容差是拒绝条件，不能作为身份已正确的充分证明。
- 同一目录对象最多对应一个显示网格。无法一对一匹配的复杂装配或分割实体保持未绑定；不自动猜测名称或序号。点击未绑定部件清除之前的配置选择。
- 已确认部件联动实体表和对象上下文；导出上下文包含显示引用，另可导出全体显示目录及用户确认的映射。两种导出均保留导入证据类别，替身目录不会变成真实工程证据。
- 映射暂存在当前页面，可导出归档；刷新、切换任务/导入/目录或运行时后需重新确认。现有材料和工况配置仍按原流程保存、冻结并验证。

运行时 JS、WASM 和许可正文由 Vite 打入本地资源，没有 CDN 或远程几何服务。只有专用 Worker 的响应允许导入器需要的动态函数，主页面不允许 JavaScript 字符串求值。Worker 无 DOM 接口，网络仅允许当前来源。关闭、卸载、源变化或 60 秒超时会取消读取并终止 Worker；渲染器释放控件、事件、几何、材质及 WebGL 上下文。

首版预览上限为 32 MiB、2000 个显示网格和 50 万个三角形。文件上限在下载与 Worker 两侧检查，复杂度上限在内核导入后检查，不能保证任意 CAD 的内核峰值内存；超时可结束后台处理。预览失败不改变归档 STEP 或原建模流程。需要支持 crypto.subtle 的本机 App/localhost；普通内网 HTTP 浏览器仍可用实体表。

Three.js 固定 0.186.1，导入器固定 0.0.23；仅作为浏览器几何显示层。热模型、网格与数值求解继续由 Icepak/PyAEDT 执行。真实 Windows 对象身份、尺寸、触控、GPU、内存和安装包加载仍待实机验收，尚不能标记 P1 工程交付完成。
